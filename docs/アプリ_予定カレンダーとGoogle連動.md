# 予定カレンダーと Googleカレンダー連動（アプリの使い方）

アプリ：https://kanesaaita.github.io/hotate-yoshoku/
場所：下メニュー **✍️ 記録 → 📅 予定**（ホームの「📅 予定」ボタンからも）

---

## 1. 予定を入れる

1. カレンダーの日付をタップ → 下に「その日の予定」が出る
2. **「＋ 予定を追加」**
3. 種類を選ぶと、その作業のよくある時間帯が自動で入る

| 種類 | 既定の時間 |
|---|---|
| 🔄 本どり（入替） | 00:00〜07:30 |
| 🪝 水揚げ・早どり | 00:00〜06:00 |
| 🎈 玉つけ（浮力管理） | 05:00〜09:00 |
| ⬇️ 沈下・浮上 | 05:00〜09:00 |
| 💰 転換・出荷 | 05:00〜12:00 |
| 🌊 放流 | 04:00〜10:00 |
| 🔍 点検・見回り | 06:00〜09:00 |

- **終了が開始より前なら翌朝あつかい。** 23:00〜07:30 は「その日の23時から翌朝7時半まで」になる
- **「何日つづけて入れるか」** で 5 を選べば、本どりのような連日作業を1回で5日分入れられる（タイトルに「1/5日目」が付く）
- 予定の **📋** ボタンで、同じ予定を翌日にコピー

カレンダーのマス目には、予定のアイコンと、**その日の記録（実績）の件数（●3）** が並ぶ。
予定どおりに動けたかが月単位で見える。

---

## 2. Googleカレンダーに入れる（3通り）

### ① 1件だけ ─ 設定なし
予定の右の **📅＋** を押す → Googleの登録画面がひらく → 保存。

### ② まとめて ─ 設定なし
**「📅 .ics で書き出し」** → ファイルができる →
パソコンのGoogleカレンダー **設定 → インポート / エクスポート → インポート** で取り込む。

※ 一度取り込むだけなので、あとでアプリ側で予定を直しても Google側は変わらない。

### ③ ボタン1つで送る／取り込む ─ 最初だけ準備が必要

**準備（1回だけ・パソコンで）**

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作る
2. 「API とサービス」→ ライブラリ → **Google Calendar API** を有効にする
3. OAuth 同意画面を作る（**外部・テスト** でよい。**テストユーザーに自分のGmailを追加**）
4. 認証情報 → OAuth クライアント ID → **ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元に **`https://kanesaaita.github.io`** を入れる
5. できた「クライアントID」（`……apps.googleusercontent.com`）をアプリの
   「🔗 Googleカレンダー連動」に貼って **💾 設定を保存**

**使い方**

- **⬆️ これから先の予定をGoogleへ送る** … 今日以降の予定をまとめて送る。
  一度送った予定は**上書き**されるので、何度押しても二重には増えない
- **⬇️ Googleから取り込む** … Google側の予定（前7日〜先60日）をアプリに取り込む

**注意**

- アプリで予定を消しても **Google側は消えない**。Google側でも消すこと
- 「テスト」の同意画面は、テストユーザーに入れたアカウントでしか使えない（家族の分も追加する）
- クライアントIDは端末のアプリ内に保存される。パスワードではないので、他人に見られても
  Google側の「JavaScript 生成元」の制限で他サイトからは使えない

---

## 3. 補足

- 予定データは **記録と同じ場所（端末内・共有中はクラウド）** に入るので、
  「⬇️ 全データ書き出し（JSON）」のバックアップに一緒に入る
- 家族共有をしていれば、**予定も家族の端末に同期される**
