## 2. 実働7日にする

**7日で終わらせる方を採る。** 理由は組合の公開動画で一致していた証言そのもの
——「**水温が上がる前に一通り作業を終えた人が、貝を殺さなかった**」。
1日早く終われば、残った①丸籠が高水温にさらされる時間もその分減る。

副次的に、**①158連/日＝約4パレット**となり、お父さんの運用単位ときれいに一致する。
予備日も実質3日（9/8〜9/10）に増える。

## 5. 便の組み方（パレット・水槽運用）

| 単位 | 量 |
|---|---|
| ①木枠パレット | **1枚 = 40連** |
| ①1日 | 138連（3.5枚）〜185連（4.6枚） |
| ②水槽 | **1つ = 70〜80連** |
| ②1日 | 471連（6水槽）〜628連（8水槽） |

**「1のしごと142連で行く」を却下した判断は正しい。**
水槽1つ分できた時点で出す方が②の陸上待機が短くなり、動画の「短時間で海に戻す」に沿う。

ただし**遠目と近場で運び方を変える**のが良い。

| | 運び方 | 理由 |
|---|---|---|
| **Day1〜4（遠目）** | **のし単位でまとめて運ぶ** | 往復90分。水槽1つずつ運ぶと航海が増えて船時間が伸びる |
| **Day5〜7（近場）** | **水槽単位で出来次第出航** | 往復65分。回転が速いので②の待機を最小化できる |

**待っている②は水槽ごと海中に沈める。** 水槽単位の運用はそのまま「水槽ごと沈める」と相性が良い。
**取水は表層から取らない**（岸壁の表層は24℃級）。

## 6. 毎日の必須チェック

### 出港前
- [ ] **作業帯の水温を実測。23℃超なら中止**
- [ ] 貝の外套膜が引っ込んでいないか（活力低下なら水温に関係なく中止）
- [ ] 翌日の**最低気温**予報（水温はこれ以下には下がらない）
- [ ] 組合ブイの**中層**水温（表層だけ見ない）

### 作業中
- [ ] **タライは先入れ先出しで使い切る。上から足さない**
- [ ] 詰め終わった②は**水槽ごと海中に沈める**（空中・重ね置き禁止）
- [ ] **取水は表層から取らない** → 高水温層より深く・低酸素層より浅く。赤川なら9〜10m
- [ ] 卵の腐った匂い＝低酸素水。取水を浅くする
- [ ] エアレーションはしない（水温が気温に近づく）
- [ ] 空中露出は1回2〜3分以内

### 吊るすとき
- [ ] **のし深度8.0m**（ふらし玉の綱を8.0mにしてピンと張る）
- [ ] ふらし玉が水面に浮いているか確認 → 浮いていれば深度は保証。**上げて確認しない**
- [ ] 魚探で水深確認。**連の下端は10.5m**になるので、水深11m未満なら浅めに調整

### 終業後
- [ ] `🔄 丸籠1→丸籠2 入替（本どり）` に のし／連数／稚貝数／**水深・水温**
- [ ] `🎈 浮力管理` に 深さ・浮き玉・沈子
- [ ] `📆 日次集計` でペース確認
