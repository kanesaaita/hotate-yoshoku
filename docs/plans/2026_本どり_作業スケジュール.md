## 2. 引き上げ順：下げた順（1部2厘 → 1部5厘 → 1部8厘）

**理由は付着物。** 1部2厘の方が海にいる期間が長く、**網に海藻・水ホヤの付着が進んでいる**。
カゴが重くなって作業効率が落ちる／網目が詰まって稚貝の生育が悪くなる、その前に片付ける。

### 網目とサイズは対応していない（2026年）

目視観察では、**最初に早どりして丸カゴに移した1部2厘が最も大きく、最後の1部8厘が最も小さい。**
網目の細かさよりも、**早く丸カゴに移したかどうかの方が成長に効いている。**

| 網目 | 早どり時期 | 現在のサイズ |
|---|---|---|
| **1部2厘** | 最初 | **最大** |
| 1部5厘 | 中間 | 中間 |
| 1部8厘 | 最後 | 最小 |

→ **Day1〜3ほど大きい貝が採れ、Day5〜7ほど小さくなる。**
　のしの用途（放流／転換販売）を決めるとき、この傾向を使い分けられる。
　詳細は [浮力と通しの計算](../knowledge/浮力と通しの計算.md)

### ただし副作用がある

最後になる**千谷B・赤川通路Aは Day7 に空くため、②の下げ先には間に合わない。**

## 7. 毎日の必須チェック

### 出港前
- [ ] **作業帯の水温を実測。23℃超なら中止**
- [ ] 貝の外套膜が引っ込んでいないか（活力低下なら水温に関係なく中止）
- [ ] 翌日の**最低気温**予報（水温はこれ以下には下がらない）
- [ ] 組合ブイの**中層**水温（表層だけ見ない）

### 作業中
- [ ] **タライは先入れ先出しで使い切る。上から足さない**
- [ ] 詰め終わった②は**水槽ごと海中に沈める**（空中・重ね置き禁止）
- [ ] **取水は表層から取らない** → 赤川なら9〜10m
- [ ] 卵の腐った匂い＝低酸素水。取水を浅くする
- [ ] エアレーションはしない（水温が気温に近づく）
- [ ] 空中露出は1回2〜3分以内

### 吊るすとき
- [ ] **のし深度8.0m**（ふらし玉の綱を8.0mにしてピンと張る）
- [ ] ふらし玉が水面に浮いているか確認 → 浮いていれば深度は保証。**上げて確認しない**
- [ ] 魚探で水深確認。**連の下端は10.5m**になるので、水深11m未満なら浅めに調整

### 終業後
- [ ] `🔄 丸籠1→丸籠2 入替（本どり）` に のし／連数／稚貝数／**水深・水温**
- [ ] `🎈 浮力管理` に 深さ・浮き玉・沈子
- [ ] `📆 日次集計` でペース確認
