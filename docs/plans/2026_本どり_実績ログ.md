## ⚠️ ①丸籠が約480連 余る見込み

初日実測の**5.99倍**で計算すると：

| | 連数 |
|---|---|
| 残り② | 3,151連 |
| 必要な① | **約526連** |
| ①の残 | **1,005連** |
| **余り** | **約480連** |

**①を全部使い切るには増幅率を3.14倍まで下げる必要がある**＝通しをかなり上げて大きい貝だけを選ぶということ。
17mmで足りるかは9/2の実測しだい。通しを上げるほど翌春の出荷重量ボーナス（1kg≒3.6円）にも効く。

**余りを放流・販売・廃棄のどれに回すかは、余りが確定する前に決めておく。**
