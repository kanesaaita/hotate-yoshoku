# 2026年 稚貝本どり作業計画（9/1開始・8日間）

作成 2026-08-17。根拠は [ナレッジベース](../knowledge/README.md) 参照。
数量は**アプリ「育成計算」の初期値**（`CALC_DEFAULTS`）で試算した例。自家の実数に置き換えて使う。

---

## 1. 日程

**実働 8日：9/1(火) 〜 9/8(火)、予備2日を足して 9/10(木) までを枠として押さえる。**

高水温・荒天で必ず飛ぶ日が出る。8日を8日枠で組むと必ず溢れるので、**10日枠で8日を回す**。

### 開始前のゲート（8/29〜8/31に判定）

9/1に着手してよいかは、次の3つを**全部**満たすかで決める。

| # | 条件 | 理由 |
|---|---|---|
| 1 | 湖内水温（自前実測・作業帯）が **23℃未満** | 作業中止ライン |
| 2 | **23℃を下回ってから概ね1週間が経っている**（＝8/25頃までに下がっている） | 水温が下がっても貝のダメージは残る。下がった直後に触ると2日後に集中して死ぬ |
| 3 | 貝の**縁が回っている**（新しい殻が伸びている）／外套膜が引っ込んでいない | 活力の直接確認 |

> **2026年の懸念：** 8/17時点で湖内は水深9mまで22℃超、中央部1m＝24.0℃。
> 気温予報では8/27頃から最低気温が17〜19℃に落ちるので、そこから水温が下がり始める見込み。
> ただし **8/30〜8/31に最高気温27℃台の戻りがある予報**。
> ここで水温が23℃に押し戻されると、条件2が崩れて **9/1着手は早すぎる**ことになる。
> **9/3〜9/5開始へのスライドを最初から想定しておく**（だから10日枠）。

### 昨年の実績との照合

2025年は1m水温が8/27頃まで23℃超が続き、そこから下がった。
条件2を効かせると開始は9月初旬。**9/1開始は例年並みで妥当な設定**。
噴火湾の標準工程でも本分散は9月中旬〜10月中旬なので、むしろ早い側。

## 2. 1日あたりの数量

### 総量（アプリ初期値での試算）

| 項目 | 数式 | 値 |
|---|---|---|
| 放流 連数 | 固定ルール（142連/のし × 19本） | 2,700連 |
| 転換販売 連数 | 1,000,000粒 ÷ (1−30%) ÷ 1,750枚 | 817連 |
| **本どり 総連数（②丸籠 3部5厘）** | 2,700 + 817 | **3,517連**（≒25のし） |
| 本どり 収容粒数 | 3,517連 × 1,750枚 | 6,154,750粒 |
| **引き上げる①丸籠** | 6,154,750 ÷ 11,000枚/連 | **約560連** |

②丸籠 在庫4,000連に対し 3,517連なので **483連の余裕**。
早どり2026実績1,108連のうち、**約半分（560連）を本どりに回す**計算。

### 8日で割る

| | 1日 | 1サイクル（3回/日） |
|---|---|---|
| **引き上げ ①丸籠** | **70連** | 23連 |
| **詰めて下げる ②丸籠** | **440連**（≒3.1のし） | 147連 |
| 稚貝 | 約769,000粒 | 約256,000粒 |

**増幅率は約6.3倍**（①1連を引き上げると②が6.3連になる）。
船の往路と復路で積む量がまったく違うので、**吊るし便の方が航海回数・時間を食う**。ここを見誤らない。

## 3. タイムスケジュール（1日）

作業帯は**深夜0時〜朝6時**。他地区の実績で、この時間帯に寄せた人が最も結果が良い。
遅くとも「3時出港・8時終了」まで。

| 時刻 | 内容 |
|---|---|
| **23:30** | **水温測定 → GO/NO-GO判定。** 23℃超なら中止。判定結果を記録 |
| 00:00 | **サイクル1開始** 出港 → ①丸籠 23連 引き上げ → 帰港・陸揚げ |
| 〜02:00 | 陸で詰め替え 147連 → 積み込み → 吊るし便出港 → 所定深度に下げる |
| 02:00 | **サイクル2**（同上） |
| 04:00 | **サイクル3**（同上） |
| 06:00 | 終了。片付け・記録入力 |
| 06:00〜07:00 | 予備（遅れた分の吸収） |

### サイクル設計の鉄則

- **1サイクル＝約2時間。陸に置く稚貝は常に1サイクル分だけ。**
  タライの中身を**全部使い切ってから**次を持ってくる。上から足さない
- **1航海の量は「船に積める量」ではなく「陸が2時間で詰め切れる量」で決める**
- **能力が足りなくても作業時間を後ろに延ばさない。** 延ばすと気温・水温の上がる時間帯に入る。
  足りないときは**日数を増やす**（だから予備2日）

### 陸側の必要処理速度

440連 ÷ 6時間 ＝ **約73連/時**（≒4,400段/日、9段/分）。
これが回らないなら、日数を10日に延ばして 352連/日 に落とす方が安全。

## 4. 吊り下げ深度（赤川エリア＝ブイ1）

詳細は [吊り下げ深度の決め方](../knowledge/吊り下げ深度の決め方.md)。

**8/17時点の赤川沖：高水温層 0〜8.5m／低酸素層 11m以深 → 安全帯は 8.5〜11m の2.5m。**

| のしの水深 | 吊り下げ（連の上端） |
|---|---|
| 8m | 逃げ場なし。**最後に回すか、この工程では使わない** |
| 9〜10m | 着底しない範囲でできるだけ深く |
| **11〜13m** | **9.0〜9.5m** ← 本命。ここに主力を配分する |
| 14〜17m | **9.0〜10.0m**（水深があっても11m以深に下げない） |

- **低酸素層の上端はほとんど動かない。高水温層の下端だけが日々動く。**
  → 低酸素側（11m）を基準に固定し、そこから動かさない
- 連が安全帯2.5mに収まらない場合、**下端を低酸素層に入れない方を優先**する
- 船の散水ポンプの取水口も同じ帯（9〜10m）から。**卵の腐った匂いがしたら浅くする**
- 下げたら**触らない**。高水温期に上げて様子を見るのが最も危険

配分の考え方：水深11〜13mののしから先に埋める。水深8m級は最終日か、使わない。

## 5. 毎日の記録（アプリ）

`🔄 丸籠1→丸籠2 入替（本どり）` に、
- のし／入替前籠・入替後籠／稚貝個数／**水深・水温**
`🎈 浮力管理` に、
- のしごとの「海面からの深さ(m)」「浮き玉」「石・沈子」、メモに根拠日付

`📆 早どり・本どり 日次集計` で 440連/日 のペースに乗っているかを毎日確認。
遅れたら**時間ではなく日数で吸収**する。

## 6. 中止・変更の判断基準

| 状況 | 判断 |
|---|---|
| 作業帯の水温 23℃超 | **中止**。地区で歩調を合わせる |
| 貝の外套膜が引っ込んでいる／活力低下 | 水温に関係なく**中止** |
| 高気温（最高27℃以上）の予報日 | 前倒しで終えるか、その日は休工 |
| 大雨後2〜3日 | 低塩分に注意（2026年8月時点の塩分は33以上で良好） |
| 水温が下がった直後 | **すぐ手をかけない。1週間置く** |
| 風が吹いて表層が下がった | **表層だけ見て判断しない。中層も確認**（風で混ざると中層まで暖まる） |
