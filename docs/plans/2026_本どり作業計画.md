## 4. 律速は「船」

陸と船の能力を並べると、ボトルネックがはっきりします。

| 工程 | 1日の所要 |
|---|---|
| 出し（3.2連/分） | 138連 → **43分** |
| 詰め（7〜8人＝7〜8連/分） | 471連 → **59〜67分** |
| **陸 合計** | **約1時間45分** |
| **船（複合便4本）** | **約4時間20分** ← **律速** |

**陸は のし1本分（145連）を33分で作れるが、船は1便65〜90分かかる。**
つまり陸は常に船を待つ側になります。この非対称を前提に組みます。

### ★ 新しいボトルネック：詰め終わった②の「船待ち」

詰めは速いので、**②丸籠が船待ちで滞留します**。ここが今回の最大の注意点。

- **②の空中・重ね置きでの待機はゼロにする**
- **詰め終わった②は必ずかけ流し水槽に沈めて船待ちさせる**（水中待機なら2時間まで許容）
- **水槽の取水は表層から取らない。** 岸壁の表層水は24℃級。
  [取水深度の考え方](../knowledge/高水温と作業判断.md#3-5-船の散水ポンプの取水深度-具体的で効く)と同じく、
  高水温層より深く・低酸素層より浅い水を使う

## 7. 吊り下げ深度（赤川エリア＝ブイ1）

### 連の寸法

```
のし面 ─┬─ 0.5m（紐）
        ├─ ┐
        │  │ 籠 10段 × 20cm = 2.0m
        └─ ┘  ← 連の下端 = のしから 2.5m
```

籠が占めるのは**のし面から0.5m〜2.5mの2m区間**（連の全長2.5m）。

### 目標深度

8/17時点の赤川沖：**高水温層 0〜8.5m／低酸素層 11m以深 → 安全帯 8.5〜11m**。

- 籠上端 ＝ のし深度＋0.5m ≥ 8.5m → のし深度 ≥ **8.0m**
- 籠下端 ＝ のし深度＋2.5m ≤ 11m → のし深度 ≤ **8.5m**

**→ のし（幹綱）の目標深度は 8.0m。** 迷ったら浅め（低酸素回避を優先）。

| のしの水深 | のし深度 | 備考 |
|---|---|---|
| 11m未満 | ─ | **連が収まらない。この工程では使わない** |
| 11〜13m | **8.0m** | 本命。主力を配分 |
| 14〜17m | **8.0m** | 水深があっても深くしない（11m以深は低酸素） |

### ★ のしの水深調査 — 測るのは「深さ」ではなく「11m以上かどうか」

のし深度8.0m ＋ 連の全長2.5m ＝ **連の下端は10.5m**。着底を避ける余裕0.5mを見て、
**必要な水深は11m以上**。逆に言えば、正確な水深は要らない。

**やり方：11mの位置に目印を付けた錘付きロープを1本作り、各のしで底に着くかどうかを見るだけ。**
着かなければ「使える」、着けば「使えない（または浅めに吊る）」。26本を短時間で二値判定できる。

- ブイ1（赤川沖）の観測水深は12m級なので、周辺ののしの多くは条件を満たす見込み
- 判定結果は アプリの のしマスターの「水深(m)」欄に記録する
  （`🗺 海図`の位置情報と突き合わせておくと翌年以降も使える）
- **着底は絶対に避ける。** 底泥の直上が最も酸素が低い

### 現状との差

ふらし玉が水面に浮いた状態でのし深度＝綱長とすると、**現状のし深度は3m**（籠3.5〜5.5m）。
高水温層のど真ん中。**足し綱を約5m追加**して8.0mにする必要がある。

### 浮き玉・ふらし玉の設計

- **ふらし玉の綱を8.0mにして、ピンと張った状態を定位置にする。**
  綱長で深度が機械的に決まるので、貝が重くなっても8.0mのまま
- **浮き玉は減らす／沈子を足して、系全体をふらし玉だけで支える状態にする**
- **ふらし玉の浮力は「9〜10月に8.0mを保てる分」だけでよい。**
  秋の鉛直混合で低酸素層は消えるので、冬に多少沈むのは問題ない（着底だけ避ける）。
  過剰な浮力を入れると、高水温期に沈められなくなる
- 見回りは**ふらし玉が水面に浮いているか**だけ見る。浮いていれば深度は保証されている。
  **上げて確認しない**

### バッファーの非対称性

| | 高水温帯（上から） | 低酸素帯（下から） |
|---|---|---|
| 境界の動き | 5日で 0m→8.5m。速い | 5日で 11m→11m。ほぼ不変 |
| 季節トレンド | 9月に向かって縮小（味方） | 秋の鉛直混合まで居座る |
| 致死性 | 段階的（22℃成長停止→27℃死） | **急性**（還元状態・硫化水素） |
| 逃げ場 | 深く下げれば逃げられる | **下は行き止まり** |

**低酸素の方がバッファーが小さい。連が安全帯に収まらないときは、下端を低酸素層に入れない方を優先する。**

## 8. 中止・変更の判断基準

| 状況 | 判断 |
|---|---|
| 作業帯の水温 23℃超 | **中止**。地区で歩調を合わせる |
| 貝の外套膜が引っ込んでいる／活力低下 | 水温に関係なく**中止** |
| 高気温（最高27℃以上）の予報日 | 前倒しで終えるか休工 |
| 大雨後2〜3日 | 低塩分に注意 |
| 水温が下がった直後 | **すぐ手をかけない。1週間置く** |
| 風で表層が下がった | **表層だけ見て判断しない。中層も確認** |
| 進捗が遅れた | **時間を後ろに延ばさず、予備日で吸収する** |
