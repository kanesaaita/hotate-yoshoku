### 引き上げ順は「1部8厘 → 1部5厘 → 1部2厘」（大きい貝から）

| 理由 | |
|---|---|
| **余る年だから** | ①1,023連＝約1,100万粒に対し、必要は660〜680万粒。**通しで4割落とす**。大きい貝を選んで詰めるのが正解（出荷重量ボーナスにも効く） |
| **放流を先に固められる** | 放流2,700連は確定数量。Day1〜6で大きい貝を使って確実に埋める |
| **飛んだときの損失が最小** | 荒天で日程が飛んだら削られるのは後半＝転換＝小さい貝。捨てても損が小さい |

> ⚠️ **逆リスク：1部2厘（ちかまB-2・B-3）を最後に回すと、8日間ずっと過密のまま高水温にさらされます。**
> 小さい貝ほど弱いので、**8月中に必ずちかまB-2・B-3の状態を見ておいてください。**
> 外套膜が引っ込んでいる・活力が落ちているようなら、**順序を入れ替える**判断が要ります。

- **①の引き上げ元は、その便の下げ先に近いのしから取る**
- **吊るす順は必ず遠目→近場**（遠目便は往復90分。最も涼しい0〜3時に充てる）

## 7. 毎日の必須チェック

### 出港前（23:00 / D型は22:30）
- [ ] **作業帯の水温を実測。23℃超なら中止**
- [ ] 貝の外套膜が引っ込んでいないか（活力低下なら水温に関係なく中止）
- [ ] 翌日の最低気温予報（水温はこれ以下には下がらない）
- [ ] 組合ブイの**中層**水温（表層だけ見ない）

### 作業中
- [ ] **タライは先入れ先出しで使い切る。上から足さない**
- [ ] 詰め終わった②は**必ずかけ流し水槽に沈める**（空中・重ね置き禁止）
- [ ] **水槽・散水ポンプの取水は表層から取らない**（岸壁の表層水は24℃級）
      → 高水温層より深く・低酸素層より浅い水。赤川なら9〜10m
- [ ] 卵の腐った匂いがしたら低酸素水。取水を浅くする
- [ ] エアレーションはしない（水温が気温に近づく）
- [ ] 空中露出は1回2〜3分以内

### 吊るすとき
- [ ] **のし深度8.0m**（ふらし玉の綱を8.0mにしてピンと張る）
- [ ] ふらし玉が水面に浮いているか確認 → 浮いていれば深度は保証。**上げて確認しない**
- [ ] 魚探で水深を確認。**連の下端は10.5mになるので、水深11m未満なら浅めに調整**

### 終業後
- [ ] `🔄 丸籠1→丸籠2 入替（本どり）` に のし／連数／稚貝数／**水深・水温**
- [ ] `🎈 浮力管理` に 深さ・浮き玉・沈子
- [ ] `📆 日次集計` でペース確認。**遅れは時間ではなく予備日で吸収**
