## 便ごとの構成

### 複合便の考え方

**往路で②を吊るし、復路でそのまま①を引き上げて帰る。** 出入港と航海回数が半分になる。

- **便1**：引き上げのみ（空荷で出港）。その日一番多くの①を取ってくる
- **便2〜（k）**：②を1のし分吊るす ＋ ①を引き上げて帰る
- **最終便**：吊るすだけ（①は取らない）

**①の引き上げ元は、その便の下げ先に近いのしから取る。**
便1だけは下げ先が無いので、作業所に一番近い①のしから。

## 毎日の必須チェック

### 出港前（23:00 / D型は22:30）
- [ ] **作業帯の水温を実測。23℃超なら中止**
- [ ] 貝の外套膜が引っ込んでいないか（活力低下なら水温に関係なく中止）
- [ ] 翌日の最低気温予報（水温はこれ以下には下がらない）
- [ ] 組合ブイの**中層**水温（表層だけ見ない）

### 作業中
- [ ] **タライは先入れ先出しで使い切る。上から足さない**
- [ ] 詰め終わった②は**必ずかけ流し水槽に沈める**（空中・重ね置き禁止）
- [ ] **水槽・散水ポンプの取水は表層から取らない**（岸壁の表層水は24℃級）
      → 高水温層より深く・低酸素層より浅い水。赤川なら9〜10m
- [ ] 卵の腐った匂いがしたら低酸素水。取水を浅くする
- [ ] エアレーションはしない（水温が気温に近づく）
- [ ] 空中露出は1回2〜3分以内

### 吊るすとき
- [ ] **のし深度8.0m**（ふらし玉の綱を8.0mにしてピンと張る）
- [ ] ふらし玉が水面に浮いているか確認 → 浮いていれば深度は保証。**上げて確認しない**
- [ ] 着底していないか（水深11m未満ののしは使わない）

### 終業後
- [ ] `🔄 丸籠1→丸籠2 入替（本どり）` に のし／連数／稚貝数／**水深・水温**
- [ ] `🎈 浮力管理` に 深さ・浮き玉・沈子
- [ ] `📆 日次集計` でペース確認。**遅れは時間ではなく予備日で吸収**

## 予備日と、飛んだときの詰め方

**9/9(水)・9/10(木) を予備日として空けておく。**

高水温・荒天で1日飛んだ場合の優先順位：

1. **放流のし（Day1〜6）を優先して埋める。** 放流2,700連は確定数量
2. **転換のし（Day6〜8）は連数で調整する。** 出荷見込みベースなので、
   1本あたりの連数を減らす／のし本数を減らす、で吸収できる
3. **D型（4のし）の日を予備日に回さない。** 予備日は疲労も溜まっているので軽い日を充てる

飛んだ日の①は、**そのまま海に置いておく**。陸に上げて待たせない。
