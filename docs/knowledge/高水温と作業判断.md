## 1. 温度の閾値

| 水温 | 起きること | 出典 |
|---|---|---|
| 20℃以上 | ホタテはストレスを抱え始める。本来は避けたい | 2023動画 |
| 22℃以上 | 2年貝・3年貝は**成長が停止**。**22℃以上が1週間以上続くと成長に明確な影響** | 2023動画 |
| 23℃近く | だんだん衰弱してくる | 2023動画 |
| **23℃** | **作業中止ライン（他地区では決定事項として運用）** | 2026動画 |
| 24℃近く | この水温で作業した地区は「全部口を開けて死んでいた」 | 2026動画 |
| 25℃超 | 衰弱 | 青森県産技センター資料 |
| 27℃ | 死亡 | 同上 |

### 閾値の読み方（ここが肝）

- 稚貝は成貝より高水温に強い。**が、それを理由に「まだ24℃だから大丈夫」と考えるのは危険。**
  上の生理データは**水槽試験**で、ストレスは高水温だけ。現場ではそこに**分散作業のストレスが上乗せ**されるので、
  実際にはもっと低い水温でへい死しうる。
- 「22.9℃が良くて23.1℃が悪い」という話ではない。**貝の状態を見る**。
  外套膜が引っ込んでいるような個体は活力が落ちているので手をかけない。
- 系統差もある（三陸産は高水温に強く低塩分に弱い等）。他地区の数字をそのまま持ち込まない。

### なぜ死ぬのか（エネルギー収支）

高水温期は餌が少なくなり、さらに水温が上がるとホタテ自体が餌を食べなくなる。
一方で水温が上がると呼吸量が増えてエネルギー消費が増える。
→ 蓄えを取り崩す。**まず生殖巣（ウロ）から、次に貝柱**。使い切ると死ぬ。

この構造から出てくる帰結：
- 歩留まりの良い（エネルギー蓄積の多い）貝は高水温ストレスに耐えやすい
- **ダメージは即日には出ない。作業の2〜3日後に集中して死ぬ。**
  さらに前年のダメージが翌年の半成貝（1年半）まで影響する

## 2. いつ作業するか

### 2-1. 「早く終わらせた人が勝つ」

令和7年の日本海側の聞き取りで、**違いを殺さなかった人＝水温が上がる前に一通り作業を終えていた人**。
細目のカゴを持っていて早期に着手できた人ほど結果が良かった。

近年は**水温の立ち上がりが従来より2週間ほど早い**。その分だけ仮分散をやれる期間が短くなっており、
仮分散ができずに本分散まで手をかけられない年も出ている。

### 2-2. 作業時間帯 — 深夜〜早朝に寄せる

常呂の耳吊りでは、
- **早い人：深夜0時に出港 → 朝6時には作業終了**
- **遅い人でも：深夜3時に出港 → 朝8時には終了**

早い時間帯に始めた人の結果が一番良かったので、皆が追随して今はこれが標準。
以前は人間の都合に合わせて暖かい時間帯にやっていた。

### 2-3. 水温が下がっても、すぐには手をかけない ★見落としやすい

23℃を下回ってから作業したのに死んだ事例がある。
作業後2日目に、**その2〜3日分の貝だけ集中して死んだ**。

原因：水温が下がっても**貝のダメージは残っている**。
青森では「**貝の縁が回ってから作業する**」（＝新しい殻が伸びてきている状態になってから）と指導している。
具体的な日数は明示されていないが、**1週間程度は置いた方がよい**（1週間〜10日という言い方）。

> **作業開始日を決めるときは「水温が下がった日」ではなく「下がってから1週間後」を起点にする。**

### 2-4. 待てるなら触らない

- 「心配で見に行った貝だけが死んでいた」（青森の報告）
- 高水温期に**上げて様子を見る**のが一番いけない。一定の深さに下げたまま、いじらない
- 令和7年に「桁をいじらない」を徹底した地区は、翌年出しの計画をほぼ達成した
- ただし**作業しないと過密になる**というジレンマは組合も認識している。バランスの問題

## 3. 作業のやり方

### 3-1. 1回に持ってくる量を絞る

船を大型化して1航海の量を増やすと、**沖に着いてから潰す（詰め替える）までの間、船上に長時間残る貝が出る**。
→ 1日の作業量は「船に積める量」ではなく「**ダメージを与えずに扱える量**」で決める。
実際、指導後は1回に持ってくる量がだいぶ少なくなった。

### 3-2. タライに前の分を残さない ★最頻出の失敗

採苗器から外した稚貝をタライ（かけ流しの水槽）に溜め、そこからカゴに移していく作業で──

**やってはいけない：** 前の分がまだ残っているのに、上から新しい稚貝を足していく。
→ 古い稚貝が底に滞留し続け、露出・停滞時間が非常に長くなる。
→ **後で死ぬ。「必要数を採った」と思っていたのに、実は見込み違いになる。**

**正しい：** タライの中身を**全部使い切ってから**、次の新しい稚貝を持ってくる。

耳吊りの作業台でも同じ。少なくなってきたからと新しいのを足し、新しい方から使うと古い方の露出が長くなる。

### 3-3. 空中露出をさせない

- 空中に出ている貝の温度は**気温に近づいていく**。気温が高ければ貝自体が25℃になる
- 水はかけているつもりでも**同じ場所にしかかかっていない**ことが多い。かかっていない場所が必ず出る
- 直射日光を当てない、熱を当てない、乾かさない
- 陸上作業は家族・アルバイトが担当することが多い。**陸側の意識改革をセットでやる**
  （沖にいる間の陸の作業品質は本人には見えない）

### 3-4. エアレーション（曝気）は逆効果 ★意外な落とし穴

作業水槽に空気を送ると、**空気の温度が水に伝わって水温が気温に近づく**。
コンプレッサーで圧力をかけるとさらに温度が上がる場合がある。高気温の日はやらない。

### 3-5. 船の散水ポンプの取水深度 ★具体的で効く

表層が高水温のとき、船底付近から取水すると**一番熱い水を貝にかけることになる**。

- **取水口を高水温層より深くする。**
  2023-07-27のブイ5（中央）の例：表面〜2.5mが22℃以上 → 「安全を見て4mの水を使えばOK」
- ただし**深すぎると低酸素水を吸い上げる**（同例では15.5mより深いと5mg/L以下）
- **低酸素水の見分け方：卵が腐ったような匂い（還元状態）。**
  汲んでいる最中にこの匂いがしたら、もう少し浅くして汲み直す

### 3-6. 冷やす工夫

- 焼酎のペットボトルに水を入れて凍らせたものを水槽に入れる
- **氷を直接入れてはいけない**（塩分が薄まる）

### 3-7. カゴ・収容密度

- **収容数は薄めに**（高水温期の基本的な考え方は「作業を控える」＋「薄めに詰める」）
- 細目のカゴがあれば早い時期から作業を進められる。持っていないなら新規購入も検討価値あり
- カゴが足りないときの代替：採苗器（スカート式・1本5〜6m）に稚貝を戻す／
  玉ねぎ袋に細かい稚貝を入れて丸カゴに追加する（噴火湾由来の技術）

## 4. 水温を読むコツ

### 4-1. 最低気温を見る ★

> 「サロマ湖の水を冷やす原動力は**最低気温**」

最高気温だけ見ていても意味がない。**最低気温が22〜23℃で続く＝水温はそれ以下には下がらない。**
逆に最低気温が落ちてくれば水温は下がり始める。

2025年の実績（センターだよりのグラフ）：
- 1m水温は7/18頃〜8/27頃まで**約1か月間23℃を超え続けた**（4mは7/25頃から）
- 7/15〜7/29に連日 最高気温30℃超・最低気温20℃超 → この時期に水温が一気に上がった
- **8/27頃にようやく最高気温が23℃を割る日が出てきて、水温が下がり始めた**

### 4-2. 風＝鉛直混合。「表面だけ暑い」はまだマシな状態

- 表層と中層が混ざる主因は**風**
- 夏の高気温期は太平洋高気圧に覆われて風が吹かない → 混ざらない → 表面だけ暑い
- **風が吹くと表面は少し下がるが、中層まで暖かくなる**
- したがって「表面が下がった」だけを見て判断してはいけない。**中層の水温も必ず見る**
- 混ざっていないうちは「下に下げれば逃げられる」。混ざってしまうと逃げ場がない

### 4-3. 外海の水温が下限になる

湖口から入ってくる水より湖内は冷たくならない。
外海（オホーツク）が21〜22℃なら、湖内はそれ以下にはならないと考える。
外海の水温は「マリンアイ」で確認できる。

### 4-4. 深ければ冷たい、とは限らない

水深43mの海域でも、令和5〜6年頃は**上から底まで24℃で逃げ場がない年があった**。
サロマ湖はさらに、深く下げようとすると**夏場の貧酸素層**に当たる。
→ [吊り下げ深度の決め方](吊り下げ深度の決め方.md) 参照

### 4-5. 個人でも水温計を持つ

組合のブイは代表点にすぎない。**自分の作業水・自分ののしの水温を毎回測る。**
実際、岸壁と作業所で実測したら24.1℃で作業していた人がいて中止させた例がある。
（多くの人は22℃前後で作業していた）

作業前日の深夜／当日早朝に水温を測り、23℃を超えるなら中止、という運用が他地区の標準。
地区でまとまって判断する。
