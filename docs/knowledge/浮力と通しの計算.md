# 浮力と通しの計算

2026年8月17〜18日の実測にもとづく。数字が増えたら追記していく。

---

## 1. 浮き玉の浮力

| 浮き玉 | 浮力 |
|---|---|
| **尺玉** | **7** |
| **尺二玉** | **12** |

※単位は現場の呼称ベース。実重量への換算が必要なら別途。

### 1連あたり浮力 ＝ 成長のものさし

```
1連あたり浮力 ＝ （尺玉の数 × 7 ＋ 尺二玉の数 × 12） ÷ その区間の連数
```

この値は「その1連を浮かせるのに必要な力」＝**カゴ自重＋稚貝の重さ＋付着物の重さ（すべて水中）**。
カゴ自重と付着物を切り分けることはできないが、**同じのし・同じカゴを時系列で追えば、増えた分がおおむね成長分**になる。

### 2026年8月18日時点（ちかまB-2・B-3）

| 状態 | 1連あたり浮力 |
|---|---|
| 尺玉が3連ごと | 7 ÷ 3 ＝ **2.33** |
| 尺二玉が3連ごと | 12 ÷ 3 ＝ **4.00** |

ちかまB-2・B-3は尺玉と尺二玉が混在しているので、**1連あたり 2.33〜4.00 の間**。
1連＝約11,000粒なので、**1粒あたり 0.21〜0.36 g相当**（カゴ自重・付着物込み・水中）。

### 記録する項目

| 項目 | 例 |
|---|---|
| 日付 | 2026-08-18 |
| のし | ちかまB-2 |
| 対象連数 | 180 |
| 尺玉の数 | 40 |
| 尺二玉の数 | 20 |
| （自動）合計浮力 | 40×7＋20×12 ＝ 520 |
| （自動）1連あたり | 520 ÷ 180 ＝ 2.89 |

**同じのしで前回との差を見る。** 差が大きい＝よく成長している（または付着物が増えている）。
のし同士を比べるときは、**網目と下げた時期をそろえる**こと。付着量が違うと比較にならない。

## 2. 2026年は成長が良い年

| 例年 | 2026年 |
|---|---|
| 早どり後1週間程度は、ストレスで成長が止まる。浮き玉の追加頻度は少ない | **早どり直後から成長し、浮き玉を頻繁に追加している** |

### 目視でのサイズ観察（8月中旬）

**一番最初に早どりして丸カゴに移したものが最も大きく、最後にやったものが最も小さい。**

つまり **網目（＝早どり時にかけた通しのサイズ）よりも、早く丸カゴに移したかどうかの方が成長に効いている。**

| 網目 | 早どり時期 | 現在のサイズ |
|---|---|---|
| **1部2厘** | 最初 | **最大** |
| 1部5厘 | 中間 | 中間 |
| 1部8厘 | 最後 | 最小 |

> **注意：網目の細かさ＝稚貝が小さい、ではない。** 2026年は逆転している。
> 「1部2厘は小さくて弱い」という前提で工程を組むと間違える。

---

## 3. 引き上げ順を「1部2厘（＝最初に下げたもの）から」にする理由

| 理由 | |
|---|---|
| **付着物** | 1部2厘の方が海にいる期間が長く、**網に海藻・水ホヤの付着が進んでいる**。カゴが重くなって作業効率が落ちる／網目が詰まって稚貝の生育が悪くなる、その前に片付けたい |
| **サイズ** | 1部2厘が一番大きいので、**先に処理する日ほど大きい貝が採れる** |
| **本どり後の待機** | 最後に残る1部8厘は一番小さいが、その分カゴが軽く付着も少ない |

---

## 4. 通しのサイズ ★要調整

### 実測（2026年8月18日・ちかまB-2）

| | 値 |
|---|---|
| ①丸籠 1段あたり | **約1,100粒** |
| 1連（10段） | **約11,000粒** |
| **16mm通しで残った数** | **1段あたり約1,000粒（91%）** |

被害（へい死）は目視ではほとんど見受けられず。状態は良好。

### 必要な歩留まりは 55%

| | 粒数 |
|---|---|
| ①在庫 1,105連 × 11,000粒 | **12,155,000粒** |
| ②必要 3,768連 × 1,775枚 | **6,688,200粒** |
| **必要歩留まり** | **55.0%** |

**16mmでは91%残ってしまい、約436万粒（39%）が行き場を失う。**

### 16mm通し後を全部詰めようとすると

| | |
|---|---|
| 必要な②連数 | 11,050,000 ÷ 1,775 ＝ **6,225連** |
| 必要なのし | 6,225 ÷ 157 ＝ **40本** |
| 手持ちののし | **24本** |

**16本足りない。のしを増やして受けるのは非現実的。**

### やること

**本どり開始前に、通し目を振って試し通しをする。**

```
1段分（約1,100粒）を各サイズの通しにかけ、残った数を数える
→ 残り 約605粒 になる目を選ぶ（1,100 × 55%）
```

16mmだと1,000粒残るので、**約395粒ぶん緩い**。18mm・20mmなど、より大きい目を試す。

通しを上げるほど**大きい貝だけを詰めることになり、翌春の出荷重量ボーナス（1kg≒3.6円）にも効く**。
余る年の定石どおり。

> 通し目を上げても605粒に届かない場合は、②の1連あたり枚数を1,800枚寄りにする、
> または余剰を放流・販売・廃棄に回すことになる。**事前に決めておく。**

# 通し（サイズ選別）と増幅率 ★2026年に分かったこと

## 1. 区分の大小は「早どり時の選別網目」で決まる

| 早どり丸籠 | 選別に使った通し | 今の貝の大きさ |
|---|---|---|
| 1部2厘 | 4.5mm | 小 |
| 1部5厘 | 5.5mm | 中 |
| **1部8厘** | **7mm** | **大** |

**網目が粗いほど、そのとき残った稚貝が大きい。** 早どりの時期の遅い早いより、
**選別網目のほうが効く**（2026-09-05に社長のお父さんが指摘、実測とも整合）。

> ⚠️ 「早どりが遅い＝成長期間が短い＝小さい」と読むのは間違い。
> 時期の差（2週間・約3.5mm）より、選別網目の差（2.5mm）＋下位カットの効果が上回る。

## 2. 通しを1mm上げると、個数で約20〜30%落ちる

2026年の実測：

| 通し | 区分 | 増幅率 |
|---|---|---|
| 16mm | 1部2厘 | 5.95 |
| 17mm | 1部2厘 | 5.78 |
| 19mm | 1部2厘 | 3.68（推定） |
| 19mm | 1部5厘 | 4.42（推定） |
| 20mm | 1部5厘 | 3.09（推定） |

- **16→17mmは3%しか落ちない**（分布の裾）
- **19→20mmは30%落ちる**（分布の山）＝ 9/5のふるい分けで実測

→ **落ち方は線形ではない。** 分布の山に刃が入ると急に落ちる。
外挿するときは1mmあたり20〜30%を見込む。

## 3. ふるい分けの取り方

**通した後の稚貝を一定量（20kg程度）取り、1段階ずつ細かいふるいにかけて重量を測る。**

2026-09-05の例（19mmを通した1部5厘 23kg・風袋除く）：

| 区分 | 重量 | 重量比 | 個数比 |
|---|---|---|---|
| 20mm以上 | 17.5 kg | 76.1% | 約70% |
| 19.5〜20mm | 1.35 kg | 5.9% | 約7% |
| 19〜19.5mm | 4.15 kg | 18.0% | 約23% |

**個数比への直し方：重量は殻高の3乗に比例する。**
各区分の代表殻高を L として、個数 ∝ 重量 ÷ L³ で割り戻す。
**詰めるのは個数（1連1,775枚＝180枚×10段）なので、効くのは個数比のほう。**

> **付着物が付いているときは、落としてから測る。** ミズホヤ等の重量が乗ると比率が狂う。

## 4. 通しの決め方 ─ ①の残量から逆算する

**必要な平均増幅率 ＝ 残りの②連数 ÷ 残りの①連数。** これを下回る通しは選べない。

例（2026-09-05時点）：残り② 1,861連 ÷ 残り① 717連 ＝ **2.60倍が下限**。

- ①に余裕がある年は通しを大きくして**粒を揃える**（下げた後の生残・成長が良くなる）
- ①が足りない年は通しを小さくして**数を確保する**
- **判断は現場で1回測れば足りる：最初の20連を通して②の連数を数える**
