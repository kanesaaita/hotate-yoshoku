# 作業工程の型と、他地区の見直し事例

出典：[2026年サロマ湖高水温対策打合せ](https://www.youtube.com/watch?v=1SQbxGGC88I)（噴火湾の事例紹介パート）

## 標準工程（噴火湾／多数派）

| 時期 | 作業 |
|---|---|
| 7月10日前後 | **種取り**（＝当地の「仮取り」「早どり」）→ 7厘目のザブトン籠または玉ねぎ袋に収容 |
| 7月下旬〜8月中旬 | **仮分散** ※近年は8月中旬だと水温が上がるので、**上旬までに終えるケースが多い** |
| **9月中旬〜10月中旬** | **本分散**（＝当地の「本どり」） |

> 本分散を9月中旬以降に置くのが標準。近年の高水温で、前工程がどんどん前倒しになっている。

## 「一発取り」 — 仮分散を省く方法

一部の漁業者が取り組んでいる工程見直し。

- 仮取りを7月10日前後 → **7月下旬まで遅らせる**（その間に稚貝を成長させる）
- 一部を**細目の丸籠に密度を薄くして収容**
- その後**9月中旬の本分散まで一切手を加えない**

**利点**：高水温期に手をかける回数がゼロになる。
**欠点**：種取りから本分散までの長期間に**付着生物**（キヌマトイガイ等）が付く。
年によっては手に負えず、やってみてやめた業者もいる。

### 一発取りを支える技術（噴火湾で試験中）

- 採苗器はフルアなどを使った**防汚網**。稚貝が10万単位で付くため、過密になると成長が悪い
- **高圧洗浄ガン（ケルヒャー等）で間引き**する
  - 落ちるのは主にイガイ。**ホタテは5mm以上になると比較的落ちにくい**
  - 間引き後の成長促進効果は調査中。即死率が上がるかどうかのデータはまだない
- 防汚網の採苗器を使っているからこそできる技、という面もある

## 高水温期の基本的な考え方（噴火湾）

明確な温度基準は決めず個人判断だが、共通する2本柱：

1. **水温が高くなったら作業を控える**
2. **収容数を薄めにする**

資材の都合で人それぞれできる範囲は違うので、そこはバランスの問題としている。

## カゴが足りないときの代替（日本海側の事例）

- 減った後の**採苗器に稚貝を戻す**（向こうの採苗器はスカート式、1本5〜6m）
- **玉ねぎ袋**に細かい稚貝を入れ、それを丸籠に入れて追加（噴火湾から来た技術）
