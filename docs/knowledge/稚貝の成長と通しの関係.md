# 稚貝の成長と通しの関係 ─ 「日が経つと倍率が上がる」

2026年の本どりで確かめたこと。**引き上げ日が数日ずれるだけで、同じ通しでも増幅率が大きく変わる。**
のしの当たり外れと取り違えやすいので、ここに残す。

---

## 1. 結論

| | |
|---|---|
| 稚貝の成長 | **約 0.26〜0.3 mm/日**（9月・水温19〜20℃） |
| 通し1mmの効き | **個数の27〜30%が落ちる**（[浮力と通しの計算](浮力と通しの計算.md) 参照） |
| **合わせると** | **1日空けるごとに増幅率が約1.09倍** |

| 空けた日数 | 倍率の伸び（0.26mm/日） | （0.3mm/日） |
|---|---|---|
| 1日 | ×1.09 | ×1.10 |
| 2日 | ×1.18 | ×1.21 |
| 3日 | ×1.28 | ×1.33 |
| **4日** | **×1.39** | ×1.46 |
| 5日 | ×1.51 | ×1.60 |
| **1週間** | **×1.77** | ×1.94 |
| 10日 | ×2.27 | ×2.57 |

> **同じ通しでも、1週間待てば取れる量が1.8倍になる。**
> 逆に言えば、**日をまたいだ倍率をそのまま比べてはいけない。**

---

## 2. 根拠（強い順）

### ① 自家データからの逆算 ★これが一番確か

同じ **1部8厘** を、4日違いで引き上げた2日分：

| 日 | のし | 通し | 実績 | 20mm換算 |
|---|---|---|---|---|
| 9/6 | 赤川通路A・B | 純20mm | ①197連 → ②532連 | **2.70倍** |
| 9/10 | 採苗地 | 45@20＋45@21＋50@22＋40@21 | ①180連 → ②502連 | **3.75倍** |

20mm換算のしかた（通し1mmで73%残る、を使う）：

```
②502 = R ×(45 + 45×0.73 + 50×0.73² + 40×0.73) = R × 133.7
R = 3.75倍
```

**4日で 2.70 → 3.75 ＝ 1.39倍。** ここから逆算すると

```
成長 = ln(1.39) ÷ (0.3147 × 4日) = 0.262 mm/日
```

**経験則 0.3mm/日 の87%。ほぼ一致する。**

> ⚠️ 私（Claude）は当初これを「採苗地の稚貝のほうが赤川通路より大きい＝のしの差」と書いたが、**誤り**。
> 引き上げ日が4日ずれたことでほぼ全部説明がつく。**日数のズレを先に打ち消してから、のしの差を見る。**

### ② 早どりから今日までの平均で検算

- 早どり（7/20頃）の殻長 **8〜10mm**（採苗器から自然に落下するサイズ）
- 9/10現在 **20〜22mm**（22mmの通しで一部が残ることと整合）
- 7/20→9/10 は52日、+12mm → 単純平均 **0.23 mm/日**
- 高水温期（8/15〜8/31）は伸びが鈍る（下記③）ので、その16日を差し引くと実働36日 → **0.33 mm/日**

**①の0.26と②の0.33で挟める。9月の水温19〜20℃なら 0.26〜0.3 mm/日 が実感に合う。**

### ③ 高水温期（8/15〜8/31）は「止まる」のではなく「鈍る」★訂正

当初ここに「22℃以上で成長が止まっていた」と書いたが、**言い過ぎだった。**

社長の観察：**この16日間、5日に1回ほど 浮き玉を6〜10個/のし 増やしていた。**
浮き玉を足すのは のし が沈むからで、沈むのは重さが増えたから。
**重さが増えているなら、止まってはいない。**

浮き玉から重さを出す：

```
6〜10個/のし × (16日 ÷ 5日) ＝ 19〜32個
尺玉7kg なら 134〜224 kg／のし   尺二玉12kg なら 230〜384 kg／のし
のし1本 ＝ 180連 × 11,000粒 ＝ 約198万粒
→ 1粒あたり 68〜194 mg 増えた
```

重さを殻長に直す（**重さ ∝ 殻長³**。9/2の落ち貝150kgから 16.5mmで0.81g と較正）：

| 1粒あたりの増加 | 15.0mm → | 16日での伸び |
|---|---|---|
| 20 mg | 15.16mm | 0.010 mm/日 |
| 35 mg | 15.28mm | 0.018 mm/日 |
| 60 mg | 15.48mm | 0.030 mm/日 |
| 110 mg | 15.85mm | 0.053 mm/日 |

**別ルート（帳尻合わせ）でも確認：** 早どり→9/10で+12mm。高水温期以外を0.30mm/日とすると、
8/15〜8/31に残るのは **0.075 mm/日**。

→ **止まってはいない。ただし通常期（0.26〜0.33）の 1/4〜1/10 に落ちていた。**

> ⚠️ **増えた重さにはミズホヤ・海藻などの付着物も含まれる。**
> 付着が重さの半分なら、殻長の伸びは上の表の半分になる。
> つまり実際の殻の伸びは、この推定よりさらに小さい可能性がある。

### ★ 浮き玉の記録は、成長の計測器になる

**浮き玉を何個足したかを のし ごとに記録すれば、重さの増え方＝成長がそのまま追える。**
アプリの「🎈浮力管理」で浮き玉の個数を入れているので、**日付と個数を残せば時系列になる。**

精度を上げるには、この3つを一度測ればよい：

1. **尺玉・尺二玉の実際の浮力（kg）** — 水に沈めて秤で引く。7／12という数字の単位を確定させる
2. **のし1本の①連数と、1連の粒数** — 連数は数える。粒数は1段抜いて数える（B-2で1,100/段の実績あり）
3. **付着物の重量比** — 籠を上げたとき、ホヤ・海藻を落とす前後で秤る

これで「浮き玉◯個＝稚貝◯mm」の換算表ができる。**海に下げたまま成長が測れる**ようになる。

### ④ 文献値（サイズ段階ごと・オーダー確認用）

| 段階 | 殻長 | 出典 |
|---|---|---|
| 着底時 | 0.3mm | [道総研](https://www.hro.or.jp/fisheries/h3mfcd0000000gsj/o7u1kr000000019q/o7u1kr000000d4fu/o7u1kr000000cf7h.html) |
| 着底後 40〜60日（採苗器から自然落下） | 8〜10mm | 同上 |
| 着底後 2〜3か月（足糸を切る） | 10〜20mm | [青森県産業技術センター](https://www.aomori-itc.or.jp/soshiki/suisan_sougou/useful/hotatecorner/mame.html) |
| **9月下旬〜10月下旬** | **20〜25mm** | [佐呂間町](https://www.town.saroma.hokkaido.jp/shoukai/hotate_youshoku.html) |
| 11〜12月放流 | 30mm以上 | 青森県産技センター |
| 翌年3月放流 | 50mm以上 | 同上 |

- 着底直後は 0.1〜0.15mm/日 と遅い（この段階の数字を持ってこないこと）
- **10〜25mmの段階が最も速く、0.3mm/日前後**
- 秋が深まると水温低下で鈍る（20〜25mm→30mmで 0.16mm/日 程度）

**本どりの時期（20mm前後）は、成長がいちばん速い段階にあたる。**

## 2.5 貝の大きさを決める2つのファクター

社長の見立て：**①早どり時の選別網目**と、**②どれだけ早く ちょうちん（採苗器）から丸籠に移したか**。
丸籠のほうが成長がよい（単位あたりの密度が低い／新鮮な海水に触れる機会が多い）。

**2026年のデータで検証したところ、どちらも効いていた。**

### 3区分を「同じ日・同じ通し」にそろえる

日数のズレを 1日×1.0859 で割り戻し、通しを20mm換算にそろえて9/10時点で比べる：

| 区分 | 早どり | 選別網目 | 元の20mm換算 | **9/10に統一** |
|---|---|---|---|---|
| **1部2厘** | 7/12〜17（最初） | 4.5mm（最細） | 3.50（9/5） | **5.29** |
| **1部8厘** | 7月末（最後） | **7mm（最粗）** | 3.75（9/10） | **3.75** |
| **1部5厘** | 7/17〜（中間） | 5.5mm（中間） | 2.03（9/5） | **3.07** |

**大小： 1部2厘 ＞ 1部8厘 ＞ 1部5厘**

殻長の差に直すと（`ln(倍率の比) ÷ 0.3147`）、1部5厘を基準に **1部2厘 +1.73mm／1部8厘 +0.64mm**。

### 片方だけでは説明できない ★これが決め手

| もし〜だけで決まるなら | 予測される順 | 実測と |
|---|---|---|
| 選別網目だけ | 1部8厘 ＞ 1部5厘 ＞ 1部2厘 | ✗ 1部2厘が1位なのを説明できない |
| 丸籠に入れた早さだけ | 1部2厘 ＞ 1部5厘 ＞ 1部8厘 | ✗ 1部8厘が2位なのを説明できない |
| **両方** | **1部2厘 ＞ 1部8厘 ＞ 1部5厘** | ✓ **一致** |

- **1部2厘**：網目は最小（4.5mm）なのに1位 → **丸籠に入れた早さ（10〜12日）が勝った**
- **1部8厘**：丸籠は最後なのに2位 → **選別網目の粗さ（7mm）が勝った**
- **1部5厘**：どちらも真ん中で、両方に負けて3位

> **「真ん中の区分が最下位」というのが、2つのファクターが逆向きに効いている証拠。**
> 片方だけなら、真ん中は必ず真ん中になる。

### 「丸籠のほうが成長がよい」の裏付け

社長の見立て（密度と海水の当たり）は、組合・行政の資料とも一致する：

- 組合の[高水温対策打合せ](https://www.youtube.com/watch?v=1SQbxGGC88I)（噴火湾の事例）
  「採苗器は**稚貝が10万単位で付く**ため、**過密になると成長が悪い**」
  → だからこそ**高圧洗浄ガンで間引く**取り組みをしている（[作業工程の型](作業工程の型.md)）
- [道総研](https://www.hro.or.jp/fisheries/h3mfcd0000000gsj/o7u1kr000000019q/o7u1kr000000d4fu/o7u1kr000000cf7h.html)：
  本分散は「大きな目合いの育成籠に**収容密度を少なくして**入替え」
  → **密度を下げること自体が本分散の目的のひとつ**
- [水産庁 適正養殖管理チェックシート](https://www.jfa.maff.go.jp/j/saibai/attach/pdf/yousyoku_kaimen-7.pdf)：
  中間育成の要点に「**貝のサイズに応じた収容密度**」が挙がっている

**採苗器（過密）→ 丸籠（疎）へ早く移すほど、その分だけ早く成長期に入る**という理屈は通っている。

### 数字の弱いところ（承知しておく）

- **1部2厘の3.50は推定値。** 9/5の混合日の分解から出したもので、2通りの解のうち片方に依存する。
  ここが動くと順位も動く。
- 3区分・3点しかないので、**2つのファクターの係数（何mmぶん効くか）は出せない。**
  順序が両方を必要とする、というところまでが言える限界。

→ **来年は殻長をノギスで直接測る。** 早どりの日・選別網目・丸籠に入れた日を のし ごとに記録し、
9月に殻長を測れば、2つのファクターの重みが分離できる。

## 3. 使い方

### 3-1. 日をまたいだ倍率は、日数で割り戻してから比べる

```
20mm換算の倍率 ＝ 実測倍率 ÷ 0.73^(通し−20) ÷ 1.09^(基準日からの日数)
```

これで初めて「のしの差」「区分の差」が見える。

### 3-2. 待つと取れる量は増える。ただし①は減らない

天候待ちは**損ではない**。日が経つほど貝は大きくなり、同じ通しでも歩留まりが上がる。
2026年は 9/3・9/4、9/7〜9/9 と休んだが、その間に稚貝は育っていた。

**ただし付着（ミズホヤ・イガイ）は待つほど進む。** そこだけが待つコスト。

### 3-3. 先の日の見込みは、成長を織り込む

例：9/10に 1部8厘が20mm換算3.75倍 なら、

| 日 | 20mm換算 | 21mm | 22mm |
|---|---|---|---|
| 9/11 | 4.08倍 | 2.98倍 | 2.18倍 |
| 9/12 | 4.43倍 | 3.23倍 | 2.36倍 |
| 9/15 | 5.68倍 | 4.15倍 | 3.03倍 |

**「今日の倍率」を明日に使い回すと、少なく見積もりすぎる。**

### 3-4. 逆に、通しを上げても量が保てる

1日空くごとに ×1.09 なので、**3〜4日空けば通しを1mm上げても同じ量が取れる**
（1mm上げる＝×0.73、4日空ける＝×1.39 → 差し引き ×1.01）。

> **「日数を待って、通しを上げる」＝ 量を落とさずに粒を大きくできる。**
> ①に余裕がない年ほど、この組み合わせが効く。

## 4. 来年に向けて測っておくこと

1. **引き上げのたびに、その のし の 殻長を実測する**（20粒ほどノギスで）。
   通しからの逆算ではなく直接の値があれば、成長曲線が1年で引ける。
   **これが最優先。** 2026年の結論はすべて「通しからの逆算」なので、直接値があれば全部確かめられる。
2. **浮き玉の追加を のし ごと・日付ごとに記録する。**
   海に下げたまま重さの増え方＝成長が追える。前提として 尺玉・尺二玉の実際の浮力（kg）を一度測る。
3. **付着物の重量比。** 籠を上げたとき、ホヤ・海藻を落とす前後で秤る。
   浮き玉から成長を読むとき、これがないと付着ぶんを引けない。
4. **水温と成長の関係。** 22℃以上で止まる／18℃前後が最適、は文献値。
   2026年の実測では高水温期も**止まってはいなかった（通常の1/4〜1/10）**。
   自分の湖でどうかは、殻長の実測と水温を並べれば分かる。
5. **早どりの日・選別網目・丸籠に入れた日を のし ごとに記録する。**
   2026年は3区分3点しかなく、2つのファクターの重みを分離できなかった。
6. **のしごとの差。** 日数と通しを割り戻してもなお差が残るなら、それが本当の場所差。
   2026年は日数で説明がついてしまったので、まだ分かっていない。
